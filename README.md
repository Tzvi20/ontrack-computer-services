# On Track Computer Services Website

A responsive static website prepared for **OnTrackComputerServices.com**.

## Files
- `index.html` — website content
- `styles.css` — design and mobile layout
- `script.js` — mobile menu and email-request form
- `assets/hero-support.webp` — hero image

## Preview locally
Double-click `index.html`, or run a local web server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing
1. Review all wording and service descriptions.
2. Replace the generated hero image with a real business photo later if available.
3. Confirm the email address `tzvi.ontrack@gmail.com` is correct.
4. The form currently opens the visitor's email application. A hosted form service can be added later.

## Recommended publishing route
Use Cloudflare Pages or GitHub Pages for free static hosting, then connect the purchased custom domain.
